# Shopreviews.com for Magento 2

Aggregate and display reviews from multiple platforms through the Shopreviews.com service.

---

## Features

- **Multi-Platform Reviews** - Sync reviews from Google, Trustpilot, Kiyoh, and 10+ other platforms
- **Automatic Synchronization** - Cron-based sync keeps reviews up to date
- **Multiple Widgets** - Textual box, carousel, and badge widgets
- **Review Overview Page** - Dedicated page with filtering options
- **Structured Data** - Google-compatible JSON-LD markup
- **Source Tracking** - See which platform each review came from

---
